# scenario

You are a senior DBA jumping in the middle of a migration because the previous DBA bailed. The customer says they need more columns in a table during the migration

## main task

update the original migration SQL script with the new fields without breaking the db or table

## additional data

### notes from previous DBA

SQL script must reflect this expanded field set. Columns for `type`, `status`, `authors`, `editors`, `created_date`, `next_review_date`, `version`, `abstract`, `keywords`, `doi`, `license`, `limitation_of_liability`, `mermaid_diagram`, `prerequisites`, and `summary` need to be added if the table was created against the old schema. Run a `PRAGMA table_info(docs_pages);` to check current columns before re-running the schema file.

### new list of fields

| Field Name | Description | MDX Type | D1/SQLite Type | Required? | Notes |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `title` | Document Title | `string` | `TEXT` | Yes | Primary identifier |
| `slug` | URL-friendly ID | `string` | `TEXT` | Yes | Auto-generated by script |
| `description` | Short summary | `string` | `TEXT` | No | SEO meta description |
| `type` | Doc Category | `string` | `TEXT` | Yes | e.g., `proposal`, `runbook`, `article` |
| `status` | Workflow State | `string` | `TEXT` | Yes | `draft`, `review`, `published`, `archived` |
| `draft` | Legacy Draft Flag | `boolean` | `INTEGER` (0/1) | No | For backward compat |
| `authors` | List of Authors | `array` | `JSON` | Yes | `[{name, title, org, url, email}]` |
| `editors` | List of Editors | `array` | `JSON` | No | `[{name, title, org}]` |
| `tags` | Keywords | `array` | `JSON` | No | `["dns", "bind", "utah"]` |
| `createdDate` | Creation Timestamp | `date` | `TEXT` (ISO) | Yes | `YYYY-MM-DD` |
| `publishDate` | Publication Date | `date` | `TEXT` (ISO) | No | `YYYY-MM-DD` |
| `lastUpdatedDate` | Last Modified | `date` | `TEXT` (ISO) | Yes | `YYYY-MM-DD` |
| `nextReviewDate` | Review Deadline | `date` | `TEXT` (ISO) | No | `YYYY-MM-DD` |
| `version` | Doc Version | `string` | `TEXT` | No | `1.0.0` |
| `abstract` | Summary (Research) | `string` | `TEXT` | No | For research papers |
| `keywords` | Formal Keywords | `array` | `JSON` | No | For academic indexing |
| `doi` | Digital Object ID | `string` | `TEXT` | No | For publications |
| `license` | License Type | `string` | `TEXT` | No | `MIT`, `CC-BY`, `Proprietary` |
| `limitation_of_liability` | Legal Clause Flag | `boolean` | `INTEGER` | No | `1` if clause is present |
| `mermaid_diagram` | Diagram Code | `string` | `TEXT` | No | Raw Mermaid syntax |
| `prerequisites` | Pre-reqs List | `array` | `JSON` | No | For runbooks |
| `summary` | Exec Summary | `string` | `TEXT` | No | For business docs |

### assumptions

- provided .sql is the original migration script
- env is Cloudflare D1
